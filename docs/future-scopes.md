# Future Scope Roadmap

## 1. Hardware productization
- Custom PCB
- Stable/protected power
- Compact enclosure
- Better connectors and cable management

## 2. Automatic compartment detection
Explore Hall sensors, reed switches, load cells, or lid-position sensors.

## 3. Advanced scheduling
- Multiple reminders per day
- Day-of-week schedules
- Snooze options
- Missed-reminder handling

## 4. Voice and accessibility
- Tamil + English prompts
- User-selectable language
- Custom voice recordings
- Improved visual indicators

## 5. Connectivity
- Phone dashboard
- Caregiver notifications
- Secure Wi-Fi configuration
- Cloud synchronization

The core device should remain functional offline.

## 6. Mobile application
Reminder setup, device status, medication schedule, event history, and caregiver access.

## 7. Reminder escalation
Voice -> buzzer -> repeated alert -> optional caregiver notification.

## 8. Data and AI
Future analytics can include acknowledgement history, adherence trends, missed-reminder statistics, anomaly detection, and personalized reminder timing.

## 9. Safety and privacy
Secure credentials, local-first operation, safe firmware updates, data minimization, audit logs, fault handling, and recovery after reboot/power loss.

## Development principle
Build reliability first, connectivity second, and AI third.
