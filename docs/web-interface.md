# ESP32 Web Interface

The prototype includes a Wi-Fi web-interface direction for editing reminder times from a phone connected to the ESP32 access point.

- SSID: SMART-PILLBOX
- Password: pillbox123
- Typical address: 192.168.4.1

The intended interface provides morning, afternoon, and night time settings, Save Reminders, and Restore Default Times.

The core reminder system should remain useful without Wi-Fi. The credentials above are demo credentials and should be changed before real deployment.
